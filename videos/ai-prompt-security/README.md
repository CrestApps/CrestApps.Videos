# AI Prompt Security

**Feature:** `CrestApps.OrchardCore.AI.Chat` (Prompt Security and Visitor Identity sections of **Settings > Artificial Intelligence**) · **Length:** see `video.json`

The Prompt Security protections, a test of an injection attempt, the message and anonymous session limits with tiers, the Visitor Identity settings and a profile's own limits. The video shows the admin only: no code or configuration files.

## Recording it again

The video was recorded on the same fresh site as the other AI videos (a real model, so the chat answers are real, and fake data). Before recording, turn off every Prompt Security option so that `02-protections` can turn them on. Record the clips in order (`02-protections`, `03-test`, `04-limits`, `05-visitor`, `06-profile`); `03-test` needs the protections saved by `02-protections`.
