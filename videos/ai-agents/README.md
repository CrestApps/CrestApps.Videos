# AI Agents

**Feature:** `CrestApps.OrchardCore.AI.Agent` and AI profiles of type **Agent** · **Length:** see `video.json`

Creating an **Agent** profile (description, availability), ticking it on an assistant's **Capabilities** tab, and a tour of the site tools of the Orchard Core AI Agent feature. The video shows the admin only: no code or configuration files.

## Recording it again

The video was recorded on the same fresh site as the other AI videos. Delete the **Research agent** profile first, and untick it on the **Support assistant**.
