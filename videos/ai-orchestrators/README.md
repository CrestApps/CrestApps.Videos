# AI Orchestrators

**Feature:** `CrestApps.OrchardCore.AI.Chat.Copilot` and `CrestApps.OrchardCore.AI.Chat.Claude` · **Length:** see `video.json`

The Default, Copilot and Claude orchestrators, the **Copilot** and **Claude** cards of **Settings > Artificial Intelligence**, and the **Orchestrator** picker of a profile. The video shows the admin only: no code or configuration files. No real credential is entered and nothing is saved: the clips only choose options and leave the fields empty.

## Recording it again

Enable the **AI Copilot Orchestrator** and **AI Claude Orchestrator** features first; the clips need no model account.
