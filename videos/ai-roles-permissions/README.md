# AI Roles and Permissions

**Feature:** `CrestApps.OrchardCore.AI` and the AI features it brings (**Access Control > Roles**) · **Length:** see `video.json`

Creating an **AI builder** role and ticking the AI permissions of the roles an AI project needs: builders, analysts, staff and anonymous visitors. The video shows the admin only: no code or configuration files.

## Recording it again

The video was recorded on the same fresh site as the other AI videos. Delete the **AI builder** role first (**Access Control > Roles**). The clips edit the **Authenticated** and **Anonymous** roles but save nothing outside the **AI builder** role.
