# Export and Import Your AI Setup

**Feature:** `CrestApps.OrchardCore.AI` with `OrchardCore.Deployment` (**Tools > Deployments**) · **Length:** see `video.json`

Building a deployment plan with the AI steps, exporting it, and importing it with **JSON Import** or **Package Import**. The video shows the admin only: no code or configuration files; the exported file is never opened, and nothing is imported.

## Recording it again

The video was recorded on the same fresh site as the other AI videos. Delete the **AI setup** plan first (**Tools > Deployments > Plans**).
