# AI Chat Analytics

**Feature:** `CrestApps.OrchardCore.AI.Chat.Analytics` (**Reports > Artificial Intelligence Reports**) · **Length:** see `video.json`

The AI Chat Session Analytics, AI Chat Extracted Data and AI Chat Conversion Goals reports, and the **Data Processing & Metrics** settings that fill them. The video shows the admin only: no code or configuration files.

## Recording it again

The demo site's **Support assistant** profile has session metrics, resolution detection, conversion metrics (goal `booked_demo`) and data extraction (`email`) on, with a 1 minute inactivity timeout. Ten short chats with fake questions were sent through the chat page (some with a fake email address, with thumbs up or down) and given a few minutes to be analyzed before recording.
