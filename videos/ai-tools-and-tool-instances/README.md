# AI Tools and Tool Instances

**Feature:** `CrestApps.OrchardCore.AI.ToolInstances` and `CrestApps.OrchardCore.AI.Agent` · **Length:** see `video.json`

What a tool is, how a profile gets built-in tools on its **Capabilities** tab (**Search tools**, **Select All Tools**,
the categories), the two permissions (**Access any AI tool**, **Access AI tool** for one tool), creating an **HTTP API
Request** tool instance under **Artificial Intelligence > Tool Instances** (**Name**, **Description**, **Base URL**,
**Authentication type**, a stored secret), giving it to a profile, the kinds of tool instances, and sharing with the MCP
server. The video shows the admin only: no code or configuration files.
